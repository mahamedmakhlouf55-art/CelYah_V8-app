# Celyah Robot V8 — Flutter app (new UI)

واجهة جديدة مستوحاة من التصميم البصري للروبوت: أسود لامع، لافندر، عيون متحركة، علامة Celyah♡.
هذا **سورس تطبيق** وليس APK جاهزًا. لم يتوفر Flutter SDK في بيئة الإنشاء للاختبار أو البناء.

## الموجود
- لوحة رئيسية وشخصية بعيون لافندر مرسومة مباشرة.
- اتصال Bluetooth BLE باستخدام Nordic UART UUIDs المتوافقة مع firmware V7.
- محادثة نصية ترسل للروبوت وتعرض ردوده.
- أوامر FACE وSERVO وCAM وCANCEL.
- صفحة للرؤية تمهيدية، بدون ادعاء وجود بث فيديو أو تحليل صور.
- إعدادات وحالة اتصال.

## غير موجود بعد
- بث الكاميرا الفعلي (يحتاج endpoint على firmware).
- تمييز الوجوه واكتشاف العوائق والحواف.
- قيادة FS90R (لا توجد أوامر قيادة متفق عليها في V7).
- تشغيل Gemini من التطبيق نفسه؛ محادثة التطبيق تمر عبر الروبوت.
- شعار بخط مطابق 100% للصورة؛ الكتابة هنا بأسلوب قريب من دون ملف خط أصلي.
